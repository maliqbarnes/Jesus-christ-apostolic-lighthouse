# JCAL Kingdom Website Demo

Node/Express demo site for **Jesus Christ Apostolic Lighthouse Kingdom Ministries International**.

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Project structure

```text
jcal-node-demo/
  package.json
  server.js
  public/
    index.html
    styles.css
    script.js
    assets/
```
