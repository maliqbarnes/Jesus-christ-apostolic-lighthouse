# JCAL Kingdom Website

Web application for **Jesus Christ Apostolic Lighthouse Kingdom Ministries International** located in Westwego / Greater New Orleans, LA.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Start Server
```bash
# Production start
npm start

# Development start with automatic restart
npm run dev
```

Then open your browser at:
```text
http://localhost:3000
```

## Key Features

- **Responsive Header & Drawer Navigation**: Smooth scrolling, mobile menu toggle, active section tracking.
- **Gather With Us Info Card**: Clear service times, church address (1001 Victory Dr, Westwego, LA 70094), and contact details.
- **Ministry Overview & Beliefs**: Core Apostolic doctrines, founding legacy tribute, servant leadership directory, and ministry branches.
- **Interactive Photo Gallery**: Auto-playing carousel slider with manual controls.
- **Livestream & Giving Options**: Direct links for Zoom/Facebook broadcasts and giving portals (Givelify, Cash App, Zelle).
- **Google Maps Integration**: Interactive map embed pointing to church location.
